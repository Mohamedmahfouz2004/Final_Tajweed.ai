# 📖 مشروع التجويد الذكي (Tajweed.AI)

مشروع تخرج متكامل يعتمد على الذكاء الاصطناعي (AI) لتحليل التلاوة المباشرة، اكتشاف أخطاء التجويد، وتقديم واجهة تفاعلية تعليمية وتدريبية لطلاب القرآن الكريم.

---

## 🛠️ هيكلية المشروع
المشروع يتكون من 3 أجزاء رئيسية:
1. **الواجهة الأمامية (Frontend):** مبنية بـ Next.js (React) وتعمل على بورت `3000`. تستخدم Clerk لإدارة حسابات المستخدمين.
2. **الخادم الأساسي (Backend):** مبني بـ Python (FastAPI)، يتعامل مع قاعدة البيانات (MongoDB) والمنطق البرمجي ويعمل على بورت `8000`.
3. **خادم الذكاء الاصطناعي (AI Backend - Muaalem):** مبني بـ Python (FastAPI/Uvicorn)، يستقبل الصوت المباشر ويحلله، ويعمل على بورت `8888`.

---

## 🚀 كيفية تشغيل المشروع خطوة بخطوة

لأي مستخدم جديد أو مبرمج في التيم، اتبع هذه الخطوات بالترتيب لضمان عمل المشروع بنجاح:

### 1️⃣ إعداد متغيرات البيئة (Environment Variables)
المشروع يحتاج إلى مفاتيح لقاعدة البيانات (MongoDB) والمصادقة (Clerk).
1. **الواجهة الأمامية:** في مجلد `myapp`، قم بإنشاء ملف `.env.local` وأضف مفاتيح Clerk:
   ```env
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_publishable_key
   CLERK_SECRET_KEY=your_secret_key
   ```
2. **الخادم الأساسي:** في مجلد `backend`، قم بإنشاء ملف `.env` (يمكنك نسخ `.env.example` إن وجد) وأضف رابط MongoDB:
   ```env
   MONGODB_URI=mongodb+srv://Tajweed:Tajweed.AI@tajweed.9hfkhdl.mongodb.net/tajweed_ai?appName=Tajweed
   ```

### 2️⃣ تشغيل الخادم الأساسي (FastAPI Backend)
هذا الخادم مسؤول عن حفظ التقدم واسترجاع البيانات.
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ Backend:
   ```bash
   cd backend
   ```
2. تفعيل بيئة بايثون الافتراضية (Virtual Environment) وتثبيت المتطلبات:
   ```bash
   source ../venv/bin/activate
   pip install -r requirements.txt
   ```
3. قم بتشغيل الخادم:
   ```bash
   python run.py
   ```
   *(ستظهر رسالة: `🚀 Starting Tajweed.AI Logic Server...` على بورت 8000).*

### 3️⃣ تشغيل الواجهة الأمامية (Next.js Frontend)
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ Frontend:
   ```bash
   cd myapp
   ```
2. قم بتثبيت الحزم المطلوبة (لأول مرة فقط):
   ```bash
   npm install
   ```
3. قم بتشغيل الموقع:
   ```bash
   npm run dev
   ```
   *(سيتم فتح الموقع محلياً على المتصفح عادةً على الرابط `http://localhost:3000`).*

### 4️⃣ تشغيل خادم الـ AI (Muaalem) - (اختياري عند التطوير)
هذا الخادم مسؤول عن تحليل الصوت واكتشاف أخطاء التجويد.
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ AI:
   ```bash
   cd muaalem
   ```
2. قم بتشغيل الخادم عبر أداة `uv`:
   ```bash
   uv run uvicorn muaalem_server:app --host 0.0.0.0 --port 8888
   ```
   *(انتظر حتى تظهر رسالة `✅ Muaalem model loaded!` ليصبح الموديل جاهزاً للاستخدام).*

* **إغلاق السيرفرات:** عند الانتهاء من العمل، يمكنك إغلاق أي سيرفر بالضغط على `Ctrl + C` في الـ Terminal.
