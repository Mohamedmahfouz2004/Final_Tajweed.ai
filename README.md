# 📖 مشروع التجويد الذكي (Tajweed.AI)

مشروع تخرج متكامل يعتمد على الذكاء الاصطناعي (AI) لتحليل التلاوة المباشرة، اكتشاف أخطاء التجويد، وتقديم واجهة تفاعلية تعليمية وتدريبية لطلاب القرآن الكريم.

---

## 🛠️ هيكلية المشروع
المشروع يتكون من 3 أجزاء رئيسية:
1. **الواجهة الأمامية (Frontend):** مبنية بـ React.js (Vite) وتعمل على بورت `5173`.
2. **الخادم الأساسي (Backend Node.js):** مبني بـ Express.js، يتعامل مع قاعدة البيانات (MongoDB) والمستخدمين ويعمل على بورت `5000`.
3. **خادم الذكاء الاصطناعي (AI Backend):** مبني بـ Python (FastAPI/Uvicorn)، يستقبل الصوت المباشر ويحلله، ويعمل على بورت `8888`.

---

## 🚀 كيفية تشغيل المشروع خطوة بخطوة

لأي مستخدم جديد أو مبرمج في التيم، اتبع هذه الخطوات بالترتيب لضمان عمل المشروع بنجاح:

### 1️⃣ إعداد قاعدة البيانات (MongoDB Atlas)
المشروع متصل بقاعدة بيانات سحابية على MongoDB Atlas لضمان مشاركة البيانات بين التيم.
1. في المسار `backend_node`، ستجد ملف اسمه `.env.example`.
2. قم بإنشاء ملف جديد بجانبه وسمّه `.env` (بدون أي إضافات).
3. انسخ محتويات `.env.example` إلى الملف الجديد `.env`.
4. قم بتغيير قيمة `MONGODB_URI` إلى الرابط المتفق عليه من فريق العمل:
   ```env
   MONGODB_URI=mongodb+srv://Tajweed:Tajweed.AI@tajweed.9hfkhdl.mongodb.net/tajweed_ai?appName=Tajweed
   ```

### 2️⃣ تشغيل خادم Node.js (البَاك إِند الأساسي)
هذا الخادم مسؤول عن تسجيل الدخول، حفظ التقدم، واسترجاع البيانات.
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ Node.js:
   ```bash
   cd backend_node
   ```
2. قم بتثبيت الحزم المطلوبة (لأول مرة فقط):
   ```bash
   npm install
   ```
3. قم بتشغيل الخادم:
   ```bash
   npm start
   ```
   *(ستظهر رسالة: `✅ MongoDB Connected` دليلاً على نجاح الاتصال بقاعدة البيانات).*

### 3️⃣ تشغيل خادم الـ AI (بايثون - Muaalem)
هذا الخادم مسؤول عن تحليل الصوت واكتشاف أخطاء التجويد.
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ AI:
   ```bash
   cd muaalem
   ```
2. (لأول مرة فقط) يجب إنشاء بيئة العمل وتثبيت المتطلبات عبر أداة `uv`:
   ```bash
   uv sync
   ```
3. قم بتشغيل الخادم:
   ```bash
   uv run uvicorn muaalem_server:app --host 0.0.0.0 --port 8888
   ```
   *(انتظر حتى تظهر رسالة `✅ Muaalem model loaded!` ليصبح الموديل جاهزاً للاستخدام).*

### 4️⃣ تشغيل الواجهة الأمامية (Frontend - React)
1. افتح نافذة Terminal جديدة وانتقل إلى مجلد الـ React:
   ```bash
   cd myapp
   ```
2. قم بتثبيت الحزم المطلوبة (لأول مرة فقط):
   ```bash
   npm install
   ```
3. قم بتشغيل الموقع:
   ```bash
   npm run dev
   ```
   *(سيتم فتح الموقع محلياً على المتصفح عادةً على الرابط `http://localhost:5173`).*

## 💡 نصائح هامة للفريق
* **ملف الـ `.env`:** هذا الملف لا يتم رفعه على GitHub (لأسباب أمنية). يجب على كل عضو في الفريق إنشائه يدوياً لديه.
* **إغلاق السيرفرات:** عند الانتهاء من العمل، يمكنك إغلاق أي سيرفر بالضغط على `Ctrl + C` في الـ Terminal.
* **إضافة دروس التجويد (Seeding):** إذا قمت بإنشاء قاعدة بيانات جديدة تماماً، يمكنك تشغيل الأمر التالي داخل مجلد `backend_node` لملء الدروس النظرية الأولية:
  ```bash
  node scripts/seed_tajweed_lessons.js
  ```
